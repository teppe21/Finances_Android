# Screenshots

Screenshots of the app will be added here. They have not been taken yet; no placeholder images are included on purpose.

Guidelines for adding them:

- Capture them from a real build with the demo data (Settings > Data management > Add demo data), never with real financial data or real notifications.
- Use PNG, one file per screen, for example `dashboard.png`, `transactions.png`, `stocks.png`.
- Reference them from the main [README](../../README.md).
